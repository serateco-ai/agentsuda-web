# 디자인 방향

기존 agentsuda의 파란 말풍선 로고, 흰색·회색·연한 파랑을 유지한다. 핵심 색은 `#2588d6`, 짙은 본문색은 `#192b3e`다. 시스템 글꼴을 사용해 외부 폰트 요청 없이 한국어를 표시한다.

메인 메시지 → 협업 대화 예시 → 세 가지 사용 방식 → 채팅 워크스페이스 순으로 구성했다. 가상 대화는 기획·구현·검토 에이전트가 하나의 작업을 이어가는 장면이며 실제 AI 호출은 하지 않는다. 실사용자 수, 고객 로고, 후기, 검증되지 않은 성능·보안 주장을 넣지 않았다.

## 참고

2026-11-19 확인:

- [LobeHub](https://lobehub.com/) / [GitHub](https://github.com/lobehub/lobehub): 약 85.8k stars. 에이전트 팀을 중심으로 설명하는 제품 메시지 참고.
- [LibreChat](https://www.librechat.ai/) / [GitHub](https://github.com/LibreChat-AI/LibreChat): 약 47.3k stars. 간결한 소개, 눈에 보이는 제품 데모, 분명한 다음 행동 참고.

방문자 통계는 검증하지 않았으며 트래픽 순위나 접속자 수를 주장하지 않는다. 코드·이미지·상표·문구를 복제하지 않았다.

## 접근성

키보드 포커스, 본문 바로가기, 의미 있는 제목 구조, 재생 제어, `prefers-reduced-motion`을 지원한다. JavaScript가 없어도 전체 데모 대화와 모든 링크를 볼 수 있다. 모바일에서는 데모의 보조 사이드바를 접고 대화 내용을 유지한다.
